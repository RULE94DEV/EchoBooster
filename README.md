## ?? About
**Echo Booster** is a low-level, high-performance system optimizer written in Python. It is designed to squeeze every drop of performance out of your Windows machine by aggressively prioritizing active games, trimming standby memory, and disabling unnecessary background telemetry.

## ? Features
- **?? Smart AI Engine:** Automatically detects active games running in the foreground, boosting their CPU priority to HIGH instantly.
- **?? Auto RAM Trim:** Clears standby memory (Standby List) and flushes DNS caches to eliminate stuttering and reduce ping latency.
- **??? Safety First (Whitelisting):** Discord, Steam, and critical Windows services are hardcoded into a whitelist to prevent accidental termination.
- **?? Advanced Windows Tweaks:** Fixes micro-stutters, stops unnecessary Windows telemetry, Superfetch, and disables Network Throttling.
- **?? Stealth Background Mode:** Uses Windows Task Scheduler to run completely silently in the system tray with full Administrator privileges on boot (bypassing UAC prompts).
- **?? Restore Defaults:** Easily revert all registry tweaks and system configurations back to native Windows defaults with a single click.

## ??? Installation

### Option 1: Download the Executable (Recommended)
1. Go to the Releases tab on this GitHub repository.
2. Download the latest G0DBoost_V5.exe.
3. Run the application (it will request Administrator privileges to apply system tweaks).

### Option 2: Run from Source
If you want to run or compile the code yourself:
1. Make sure you have Python 3.10+ installed.
2. Install the required dependencies: pip install customtkinter psutil requests pywin32 pillow
3. Run the main file as Administrator: python main.py
